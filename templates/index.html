VERIFICATION WORKFLOW

How NoticeShield Protects College Notices

Simple QR codes can be copied and pasted onto fake posters. NoticeShield combines asymmetric cryptography with AI OCR content inspection to ensure complete tamper detection.

1. Digital Signing

Administrators register notice fields. The system forms canonical JSON and signs it with a backend Ed25519 private key.

2. Tamper-Proof QR

A high-error-correction QR code containing the unique Notice ID is embedded into the official downloadable PDF notice.

3. Multi-Pass OCR

When a student uploads a screenshot or forwarded image, OpenCV extracts the QR and EasyOCR reads the visible text.

4. Dual Validation

The public key validates the signature, while semantic analysis compares dates, venue, and title against the official ledger.

CYBERSECURITY ARCHITECTURE

Why Standard Image Hashes Fail and How NoticeShield Solves It

Standard SHA-256 Image Hashes Break on Forwarding

WhatsApp, Telegram, and screenshotting recompress image pixels. A single changed pixel alters an entire file hash, causing false tampering alarms for genuine notices.

NoticeShield Signs Canonical Semantic Data

We sign deterministic canonical JSON (title, dates, venue, issuer). Visible content is checked with intelligent OCR so genuine screenshots verify cleanly while changed dates or venues get caught immediately.

Never Trust QR Codes in Isolation

Malicious actors often crop a real QR code and paste it on a fake circular. NoticeShield cross-references visible OCR fields against the cryptographically signed ledger.
